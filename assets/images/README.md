# Original site assets — migration blocker

No original image files or source archive were present in this repository when the site rebuild began. The public-page crawl exposes text and page structure but does not provide a reliable inventory of the original image file URLs, image binaries, licensing details, or alt text.

Do not substitute guessed filenames or generated artwork for original brand/project assets.

## Needed to complete this migration
- Original logo / wordmark files, if any
- Original hero, portfolio, and project screenshots
- Any other site images and their intended page placements
- Alt text or confirmation of the subject for accessibility
- Confirmation that the files may be copied into this repository

Place supplied assets under `assets/images/`, then update page references and verify image loading on the deployed site.

## Current state
The rebuilt pages currently use CSS and text-based layouts rather than embedded original image files. Original imagery is **not yet migrated**.
